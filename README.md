# منصة الجودة الأكاديمية الذكية — المرحلة 1

متابعة اكتمال ملفات المقررات لكلية الحاسبات والمعلومات بجامعة الباحة. التجربة الأولى: قسم علوم الحاسب (59 مقررًا، 24 مستخدمًا).

## ما تقدمه المرحلة 1
- **الدخول:** البريد الجامعي ثم يظهر الاسم تلقائيًا؛ أول دخول يختار العضو كلمة مرور، وبعدها البريد وكلمة المرور (قفل 15 دقيقة بعد 5 محاولات خاطئة). كلمة مرور العميد يعيّنها المسؤول فقط.
- **اختيار المقررات:** يختار الأستاذ مقرراته في أول دخول كل فصل، مع خيار «أنا منسق المقرر»؛ ويعتمد رئيس القسم التوزيع.
- **الرفع:** ملفات أو مجلد كامل بصيغة ZIP. فحص النوع الحقيقي للملف، وكشف الملفات الفارغة والمكررة، وحفظ كل الإصدارات.
- **الفرز التلقائي:** توصيف / نظري / عملي / تقييم من الاسم والمجلد والمحتوى. ما لا تحسمه القواعد يقرؤه Claude (`ANTHROPIC_API_KEY`، ويقرأ الملفات الممسوحة كصور)، وما لا يحسمه بثقة 70% يذهب لفريق المشروع.
- **الاكتمال:** ✓ ✗ ? N/A لكل مكوّن، ونسبة لكل مقرر وللبرنامج (المقررات المطروحة فقط).
- **التذكيرات:** تبدأ بعد اعتماد رئيس القسم، وتتكرر كل N يوم، وتتوقف تلقائيًا عند الاكتمال. بدون إعداد SMTP تُسجَّل «محاكاة».
- **مركز القرارات الذكي:** عند رفع توصيف المقرر يقرأ Claude التوصيف والوثائق ويقارنها بالخطة، ويولّد مسائل تحتاج قرارًا مع أدلة مقتبسة حرفيًا (يُتحقق من وجود كل اقتباس في الملفات قبل عرضه)، ويسندها للمنسق أو رئيس القسم. اعتماد أو تأجيل أو تصعيد لرئيس القسم/العميد، ومساعد ذكي محصور في المسألة.
- **اللوحات** لكل دور (تتحدث كل 15 ثانية)، **وسجل نشاط** لا يُعدّل.

## التشغيل المحلي (Windows)
```bash
# الخادم الخلفي
cd backend
python -m venv .venv && .venv\Scripts\pip install -r requirements-dev.txt
.venv\Scripts\python -m app.cli init "<مسار>\المستخدمون_وتوزيع_المقررات_v3.xlsx"
.venv\Scripts\python -m app.cli set-password "<اسم العميد>"
.venv\Scripts\python -m app.cli add-tester "<الاسم>" <البريد>   # حساب تجريبي معزول، يدخل مباشرة بإدخال بريده
.venv\Scripts\python -m uvicorn app.main:app --port 8000

# الواجهة (نافذة أخرى)
cd frontend
npm install && npm run build && npx next start -p 3000
```
ثم افتح http://localhost:3000

محليًا تعمل المنصة بـ SQLite وتخزين ملفات محلي في `backend/data`. على الخادم تعمل نفس الشيفرة بـ PostgreSQL وMinIO.

## التشغيل على الخادم
```bash
cp .env.example .env   # عبّئ كلمات المرور والمفتاح السري
docker compose up -d --build
docker compose exec backend python -m app.cli init /path/to/users.xlsx
docker compose exec backend python -m app.cli set-password "<اسم العميد>"
```
